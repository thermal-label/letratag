# Interface: RawImageData

Raw RGBA image data, compatible with browser ImageData and
@napi-rs/canvas ImageData.

## Properties

| Property | Modifier | Type |
| ------ | ------ | ------ |
| <a id="property-data"></a> `data` | `readonly` | `Uint8Array` |
| <a id="property-height"></a> `height` | `readonly` | `number` |
| <a id="property-width"></a> `width` | `readonly` | `number` |
